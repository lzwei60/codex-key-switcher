# v1.0.4 发布说明

## 新增内容

- 同一供应商下支持按模型配置 Responses、Chat Completions 或 Anthropic Messages 协议。
- 支持为每个模型配置推理参数和图片输入能力，并支持继承供应商默认值。
- 支持从上游拉取模型列表、逐模型检测，以及保存未检测模型前的确认提示。
- 本地路由根据请求中的 `model` 选择当前供应商下的实际模型。
- 生成更完整的 Codex 模型 Catalog，并增加 Catalog 完整性校验工具。
- 增加协议转换、模型目录、超时、断流和跨模型路由回归测试。
- 托盘菜单、供应商、诊断、设置和用量页面补充中英文显示。

## 修复内容

- 修复原生 Responses 流直接输出文本或提前结束时的事件序列错误；异常流只返回失败，不会伪造成功完成。
- 修复 Chat Completions 和 Anthropic 的系统指令、函数工具历史及完整消息历史转换。
- 修复跨协议仅携带响应 ID 时静默丢失上下文的问题，改为提前返回明确的 400 错误。
- 修复不支持图片或文件输入的模型被错误转发的问题。
- 修复上游响应头、请求体、普通请求和流式响应缺少分阶段超时的问题。
- 修复正常读取请求体后被误判为客户端断开的网关问题。
- 修复 DeepSeek 等 OpenAI 兼容上游的协议路径、模型映射和请求头处理。
- 修复模型别名重复、模型能力字段丢失和模型修改后检测状态过期的问题。

## 优化内容

- 优化模型编辑器布局和高级模型能力配置。
- 优化运行时错误本地化，提升中英文界面一致性。
- 优化模型 Catalog 缓存模板匹配与默认字段补全。
- 优化默认模型切换通知，明确默认值不会热切换已有会话。
- 优化流式背压、客户端断开清理和失败用量记录。

## 升级与风险提示

- 旧供应商、凭据、用量统计和连接设置会保留。
- 修改模型或连接模式后，需要重新加载 Codex 模型列表；跨协议继续会话需要提交完整历史。
- Chat Completions 和 Anthropic 模型必须使用本地路由；直连模式要求 Responses 协议。
- 当前安装包未签名、未 notarize。Windows 和 Linux 安装包仍需在目标系统完成安装启动冒烟测试。

## 安装包

- macOS Apple Silicon：`Codex-Key-Switcher-1.0.4-arm64.dmg`
- macOS Intel：`Codex-Key-Switcher-1.0.4-x64.dmg`
- Windows x64：`Codex-Key-Switcher-Setup-1.0.4-x64.exe`
- Linux x64：`Codex-Key-Switcher-1.0.4-x86_64.AppImage` 和 `Codex-Key-Switcher-1.0.4-amd64.deb`
